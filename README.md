# COURTSIDE Demo

An interactive classroom prototype for planning student sports in Macau.

Open the [demo](https://m1kywuu.github.io/courtside-demo/) in your browser. The people, prices, availability, bookings and offers are examples. The demo does not send invitations or make real bookings or payments. Changes stay in the browser.

The seven example days start on the current date in Macau when the demo opens or reloads.
